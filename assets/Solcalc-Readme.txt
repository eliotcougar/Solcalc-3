Solcalc - Solution Calculator

Use Ctrl+1, Ctrl+2 and Ctrl+3 to switch calculators.
Leave the quantity you want to calculate blank.
The Substance button searches English names, the selected language, formulas,
synonyms and CAS numbers. Selection applies to Mass/Volume and Stock preparation.
The offline catalog contains 104,087 ChEBI entries, with separate Russian translations.
ChEBI release 257: https://www.ebi.ac.uk/chebi (CC BY 4.0; filtered for Solcalc).
Original names, molar masses and Russian translations take precedence.
PubChem is optional online search; Import opens an editor for review before Save.
Network errors do not prevent offline use. Existing user CAS entries are retained.

User substances need a molar mass and at least one name.
Formula, CAS and synonyms are optional. Delete removes only user entries.
Deleting a customization restores the bundled substance.

Each Windows user's data stays in that user's profile:
  %LOCALAPPDATA%\Solcalc\user-substances.sqlite
  %LOCALAPPDATA%\Solcalc\settings.ini
Back up this folder when moving to another computer.
Updates and uninstall preserve this folder, including migration backups.

Setup supports current-user installation and installation for all users.
All-users installation requires administrator permission.
Shared installation does not share users' databases or settings.
